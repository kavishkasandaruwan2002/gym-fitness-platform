# Forged - React JS Gym Website Template

Forged is a premium Gym website template built for elite training clubs, boutique gyms and performance coaching brands. It features a bold hero section, membership pricing, athlete testimonials, FAQ accordion, contact form and insight blog previews. With dark luxury styling.

**Live Preview:**
https://forged.prebuiltui.com

## Installation Guide


### Next.js

1. Navigate to the `/nextjs` directory.
2. Install dependencies:

   npm install

3. Run development server:

   npm run dev
